# Прядь — сайт студии волос

Статический сайт: `index.html`, `styles.css`, `main.js`, `data.js`.
Сборка не нужна — достаточно открыть `index.html` в браузере.

## Что где менять

- **Контакты и ник Telegram** — объект `CONFIG` в `data.js`.
- **Услуги и цены** — массив `SERVICES` в `data.js` (сайт берёт прайс оттуда;
  `SERVICES.md` — справочная версия прайса).
- **Фото на главном экране** — положите файл в `img/hero.jpg`, он подхватится сам.

## Запись

Кнопки «Записаться» открывают чат в Telegram с заготовленным текстом
(например, «Здравствуйте! Хочу записаться: Балаяж / шатуш.»).
Сайт не собирает персональные данные.
