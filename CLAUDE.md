# TORTÉ — память проекта

Этот файл — полная память по проекту: что делаем, что решили, что отвергли,
как собирать и проверять. Читать первым в каждой новой сессии.
Обновлять после каждой заметной правки.

## Проект

- Сайт парикмахерской студии **TORTÉ** (Москва). Только парикмахерские услуги —
  **никакого маникюра/педикюра**.
- Репозиторий `uydilevich-ctrl/hair-salon-site`, рабочая ветка
  `claude/barber-services-website-ibgdwl`, открыт PR #1
  (https://github.com/uydilevich-ctrl/hair-salon-site/pull/1). Пушить только в эту ветку;
  новые PR не создавать без просьбы.
- Сайт публичный. Своей формы записи нет и персональные данные не собираются —
  **запись только переходом в Telegram** с готовым текстом
  (`https://t.me/<ник>?text=...`). Плюс WhatsApp и телефон.
- Общение с владелицей — на русском, коротко и по делу, показывать результат
  (скриншоты/превью).
- Коммиты заканчиваются строками `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
  и `Claude-Session: https://claude.ai/code/session_014QPMSbkz6vvhUs7y99RGpz`;
  идентификатор модели в коммитах/коде не писать.

## Видео-обложка (выбран вариант «Б»)

- Видео владелицы (из золотой линии вырастают волосы). Обработка `ffmpeg`
  (`imageio-ffmpeg`, бинарник `.../imageio_ffmpeg/binaries/ffmpeg-linux-x86_64-v7.0.2`):
  звук убран, бесшовный цикл **6,8 с** — кусок 1,2–8 с + плавный переход (xfade 1,2 с)
  в начало 0–1,2 с, `fps=24`, H.264 crf 24 `+faststart`; WebM: VP9 crf 36.
  Исходник в репозитории не хранится — только готовые `video/*`.
- `<video class="hero-film" autoplay muted loop playsinline preload="auto" poster="video/hero-poster.jpg">`.
- Слева сливочная вуаль под текст; весь текст и меню оливковые.
- Телефон (≤760 px): вуаль сверху (`rgba(246,241,232,.92)` → `.82` на 48% → прозрачно на 78%),
  текст наверху, `object-position: 50% 30%`.
- **Черепахи в меню на обложке нет** (`.hero-video .nav { justify-content:flex-end }`).
  Блок названия поднят сразу под меню (`margin-top: clamp(8px,4vh,48px)`).
- Блок: inline-SVG черепаха `.brand-mark` + `h1.brand-name` (буквы T-O-R-T-É отдельными span)
  + `.brand-sub` «Hair studio · Moscow» с золотой линией; слоган **«Волосы с характером»**
  («Волосы» оливковым, «с характером» — курсив золотом + рукописный золотой штрих
  `.tag-stroke`); абзац + кнопка «Выбрать услугу».
- `prefers-reduced-motion`: видео на паузе (постер), всё показано сразу, без анимаций.

## Анимация логотипа и текста

**При загрузке:**
- черепаха рисуется линиями (stroke-dash, `pathLength="1"`, `draw` 2,2 с; пути 6–9 —
  голова, лапки, хвост — с задержкой 0,5 с);
- буквы TORTÉ по очереди поднимаются и проявляются из размытия (`letterIn`, 0,5…0,98 с);
- золотая линия раскрывается от центра (`grow` 1,2 с), подпись проявляется (`fadeIn` 1,5 с);
- слоган по буквам (`.ch` с `--i`/`--d`): «Волосы» с 1,3 с, «с характером» с 1,9 с;
- штрих под «с характером» рисуется с 2,4 с; абзац и кнопка — 2,6 с.

**На каждом круге видео** (JS ловит скачок `currentTime` назад в `timeupdate`, через 1,3 с
ставит класс `.wave` на `.hero-content` — в момент, когда из линии появляются волосы).
Владелица просила, чтобы **двигалось всё, а не только «с характером»**:
1. золотой блик бежит по линиям черепахи (клон контуров в `<g class="glint">`,
   `stroke: gold-light`, ширина 2.8, `dasharray .12 1.2`, `glint` 2,2 с);
2. буквы TORTÉ по очереди приподнимаются и светлеют (`letterLift`, 0,3…0,7 с);
3. золотая линия раскрывается заново (`regrow`, 0,8 с);
4. волна по «Волосы» (`letterWaveInk`, с 1 с);
5. золотая волна по «с характером» (`letterWave`, с 1,35 с);
6. штрих рисуется заново (1,9 с).

Возможные следующие шаги (предлагались, не сделаны): лёгкое постоянное мерцание линии
между волнами — или, наоборот, оставить волну только на черепахе и слогане.

## Превью и проверка

- Превью — приватный артефакт https://claude.ai/artifact/BEbfgA3GhrERXwuQXtesHn
  (последняя версия — 14). Обновлять тем же URL (`Artifact` с `url`).
- Сборка превью: один HTML — CSS и JS встраиваются, SVG из `brand/final` как data URI,
  видео передаётся через `files` (`video/hero.mp4`, `video/hero.webm`, `video/hero-poster.jpg`):

```python
import re, base64
h = open('index.html').read()
head = re.search(r'<head>(.*?)</head>', h, re.S).group(1)
body = re.search(r'<body>(.*?)</body>', h, re.S).group(1)
head = re.sub(r'<meta charset[^>]*>\n|<meta name="viewport"[^>]*>\n', '', head)
head = head.replace('<title>TORTÉ — студия волос в Москве</title>', '<title>TORTÉ studio</title>')
head = head.replace('<link rel="stylesheet" href="styles.css">', '<style>\n' + open('styles.css').read() + '\n</style>')
uri = lambda p: 'data:image/svg+xml;base64,' + base64.b64encode(open(p, 'rb').read()).decode()
for f in set(re.findall(r'brand/final/[\w\-]+\.svg', head + body)):
    head, body = head.replace(f, uri(f)), body.replace(f, uri(f))
body = body.replace('<script src="data.js"></script>', '<script>\n' + open('data.js').read() + '\n</script>')
body = body.replace('<script src="main.js"></script>', '<script>\n' + open('main.js').read() + '\n</script>')
open('<scratchpad>/prjad-preview.html', 'w').write(head.strip() + '\n' + body)
```

- Проверка: `python3 -m http.server 8765` + Playwright
  (`require('$(npm root -g)/playwright')`, `ignoreHTTPSErrors:true`), экраны 1440×900 и 390×844.
  В Playwright-Chromium нет H.264 — играет WebM. Google Fonts в песочнице иногда не грузятся.
- Брейкпоинты вёрстки: 960 и 760 px.
