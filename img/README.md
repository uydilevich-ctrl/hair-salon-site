# Фото для сайта

- `hero.jpg` — главный экран (горизонтальное, от 1800 px по ширине).
- `works/N-before.jpg`, `works/N-after.jpg` — работы «до / после»
  (вертикальные 3:4, примерно 900×1200; ракурс и свет на обоих фото одинаковые).
- `salon/1.jpg` … `salon/5.jpg` — интерьер. Первое фото показывается крупно.

Подписи и список работ — в `data.js` (`WORKS`, `SALON_PHOTOS`).
Пока файла нет, на его месте показывается заглушка.
Перед загрузкой сожмите фото (например, squoosh.app) — до 300–400 КБ на файл.
